## Task 2 — Homepage
Responsive single-page website built with vanilla HTML, CSS and JavaScript.
No frameworks used.

### How to run
1. Clone the repository
2. Open `index.html` in any browser

### Tech Stack
- HTML5 (semantic)
- CSS3 (Flexbox + Grid)
- Vanilla JavaScript

### Features
- Sticky navigation with smooth scroll
- Scroll reveal animations
- Mobile responsive with hamburger menu
- Contact form with success state
